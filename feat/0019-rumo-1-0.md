# 0019 — Rumo à 1.0: um app só, assinatura própria e README de usuário

**Data:** 2026-09-21 · **Status:** ✅ concluído

## O que mudou

- **Um app só.** A tela **Configurações › Inteligência artificial** (Principal, Reserva, Testar, chave no
  Keystore do Android), que só existia na `release/teste-usuarios`, passou para o app principal. O id
  definitivo é `com.getulio.izifnc` e o nome é "IziFnc": acabou a versão "IziFnc Teste".
  - A chave configurada no app vale mais que a embutida no build; sem nenhuma guardada, o app cai no
    `--dart-define=GROQ_API_KEY` (é como se desenvolve com a API direto).
  - Mensagens e comentários que falavam de "engrenagem na tela do mês" e "versão dos testadores" foram
    atualizados para o menu lateral.
  - Entrou também `flutter_secure_storage` e a tela de IA na matriz de telas da 0016 (Principal e Reserva
    preenchidas, com endereço e modelo compridos).
- **Assinatura própria.** O APK de release passa a ser assinado com um keystore do projeto
  (`android/key.properties`, ignorado pelo git; o `.jks` e a senha ficam em `_local/keys/`). Sem o
  `key.properties` (CI), o build cai na chave de debug e continua funcionando.
- **README de usuário**: "Como usar" (instalar o APK, primeiros passos, importar a planilha, backup,
  privacidade, limites), e o status do topo atualizado.

## Por quê

O autor decidiu distribuir a 1.0 como **APK no GitHub Releases** e manter **um app só, com chave de IA
própria de cada pessoa**. O plano "serviço IziFnc" (limite de 1 importação e 5 relatórios por mês, sem o
usuário trazer chave) exige um servidor e ficou para depois da 1.0.

- **Por que keystore próprio agora:** o Android só instala uma atualização por cima se a assinatura for a
  mesma. Com a chave de debug (qualquer máquina gera uma diferente) cada versão seria uma reinstalação
  e apagaria os dados. **Trocar de chave depois de publicar não tem volta.**
- **Trazer os arquivos da release em vez de mesclar a branch:** a `release/teste-usuarios` tinha o id `.teste`,
  o rótulo "IziFnc Teste" e um README de testadores, tudo que não deve entrar na `main`. Só entraram os
  arquivos de IA e os testes deles.
- **Os testadores atuais** têm o app "IziFnc Teste" (outro id): o app novo **não herda** os dados dele.
  Caminho: instalar o IziFnc novo e reimportar a planilha (o backup em Configurações › Dados vale de
  agora em diante, dentro do mesmo id).

## Como verificar

1. `flutter analyze`, `flutter test`, `dart run tool/validar.dart`.
2. No aparelho: ☰ › Configurações › Inteligência artificial abre, salva uma chave (mostrada mascarada)
   e ela continua ali depois de fechar e abrir o app.
3. APK assinado: `flutter build apk --release --target-platform android-arm64` e
   `apksigner verify --print-certs` mostra `CN=IziFnc, O=IziFnc, C=BR`.
